# Hardening Control Platform

Расширяемая веб-платформа для аудита и безопасного харденинга Linux-серверов.

MVP показывает полный демонстрационный цикл: выбор профиля, запуск аудита, результаты проверок, план исправлений, имитация резервных копий, повторный аудит и отчет “до/после”. Веб-часть не меняет реальную ОС и безопасно разворачивается на Vercel.

Дополнительно реализован локальный Python-агент в режиме “только аудит”. Он выполняет реальные проверки хоста, возвращает JSON-отчет и подключается к сайту через локальный промежуточный сервер.

## Основные экраны

- `/` панель со статусом демо-режима и схемой процесса.
- `/profiles` четыре профиля аудита: базовый Linux, безопасность SSH, усиление веб-сервера и усиление Docker-хоста.
- `/audit/[profileId]` запуск демо-аудита.
- `/audit/[profileId]/results` оценка, риски, найденные проблемы и фильтры.
- `/remediation` выбор исправлений, риск изменения, затрагиваемые файлы, резервная копия, откат и шаги выполнения.
- `/reports` отчет “до/после”, экспорт JSON и HTML.
- `/guide` инструкция и сценарий демонстрации MVP.
- `/agent` описание локального Linux-агента.
- `/agent/import` автоматический или ручной импорт JSON-отчета агента, история, сравнение отчетов и план исправлений.

## Краткая инструкция по работе на сайте

1. Откройте главную страницу и проверьте, что платформа работает в демо-режиме.
2. Перейдите в `Профили`, выберите профиль аудита и нажмите `Запустить аудит`.
3. На странице результатов изучите оценку защищенности, риски и таблицу найденных проблем.
4. Используйте фильтры по риску и категории, затем перейдите к выбору исправлений.
5. В `Исправлениях` отметьте нужные действия и нажмите `Применить демо`.
6. Откройте `Отчеты`, чтобы увидеть сравнение “до/после” и скачать JSON или HTML.

Подробная инструкция находится в `docs/site-guide.md`.

## Связка с локальным агентом

Запустить промежуточный сервер агента:

```bash
cd agent
python3 server.py
```

Затем открыть на сайте `/agent/import` и нажать `Получить аудит от агента`.

Страница импорта сохраняет историю отчетов в браузере, позволяет сравнить два запуска и формирует безопасный план исправлений без применения изменений.

Ручной вариант:

```bash
cd agent
python3 agent.py audit --profile basic_linux --pretty > agent-report.json
```

После этого файл можно загрузить на странице `/agent/import`.

Для установки агента как локального systemd-сервиса используйте:

```bash
cd agent
./install.sh --dry-run
sudo ./install.sh --enable --start
./doctor.sh
sudo ./uninstall.sh --dry-run
```

## Термины

- Аудит: проверка системы на небезопасные настройки.
- Результат проверки: найденная проблема, успешная проверка или пункт для ручного анализа.
- Исправление: действие для устранения найденной проблемы.
- Резервная копия: сохранение состояния перед изменением.
- Откат: возврат изменения к предыдущему состоянию.
- Профиль: набор правил под сценарий аудита.
- Агент: локальный модуль для реальных проверок хоста.

## Демо-режим

Демо-режим использует локальные данные и работает безопасно в браузере. Применение исправлений имитирует создание резервной копии, применение изменений, проверку и повторный аудит, создает отчет в памяти браузера и не выполняет системные команды.

## Локальный Linux-агент

Папка `agent` содержит безопасную audit-only версию Python-агента. Агент запускается на Ubuntu/Debian, определяет ОС, проверяет доступные настройки SSH, UFW, fail2ban, обновлений, Nginx и Docker, а затем возвращает JSON-отчет. Команды реального исправления и отката пока являются заглушками и не изменяют систему.

## Деплой на Vercel

1. Опубликовать проект на GitHub.
2. Создать проект в Vercel из репозитория.
3. Указать `web` как корневую директорию.
4. Использовать стандартные команды Next.js: install `npm install`, build `npm run build`.

## Ограничения первой версии

- Нет реального изменения Linux-хоста.
- Нет запуска `systemctl`, `ufw`, `sshd`, `nginx` на Vercel.
- Нет контейнеризации.
- Нет многопользовательской авторизации.
- Нет полной интеграции с Lynis/OpenSCAP.
