# Остановка сборки при неполной загрузке индексов APT

16 ноября, локальное продолжение после функциональной приёмки.

## Изменение

Прежний runtime-шаг Dockerfile мог продолжить установку пакетов после
сетевого отказа `apt-get update`: APT по умолчанию возвращает 0 для некоторых
временных ошибок и предупреждает об использовании старых индексов.
Добавлен `APT::Update::Error-Mode=any`: такой отказ останавливает цепочку
до установки. Проверка подписей и прежний запрет повторов сохранены.
[Поведение APT в официальном исходнике](https://github.com/debian/apt/blob/main/apt-pkg/update.cc).

Регрессия берёт параметры непосредственно из Dockerfile и запускает настоящий
APT с отдельными временными индексами. Локальный порт зарезервирован, но не
прослушивается: загрузка гарантированно отклоняется. До исправления тест
провалился: установка могла начаться. После исправления APT завершает шаг
ошибкой; удаление защитного параметра снова воспроизводит ложный успех.
Системные индексы и пакеты тест не изменяет.

## Проверено

- Точечный RED/GREEN на управляющем Linux.
- Все **251 deployment-тест без пропусков** в отдельном контейнере образа
  `00f0ad6c`, с переданным снимком изменённых исходников только для чтения.
  Сеть отключена; настоящий APT доступен, новая регрессия выполнена.
- Свежие подписанные индексы bookworm / updates / security в другой
  одноразовой копии: симуляция upgrade — **0 изменений**. Установленные версии
  Kerberos, Pillow, libxml2, SQLite, OpenSSH и GLib совпали с candidate.
- Предел контейнера 1 ГиБ без дополнительного swap; минимальный
  MemAvailable успешного набора — **4 600 901 632 байта**. Guard 2,25 ГиБ
  и OOM не сработали. Временные контейнеры удалены.

Первый полный прогон тестового контура имел девять отказов из-за `noexec`
на его временном каталоге: тестам нужны исполняемые SSH/apt/chroot fixtures.
Исправлено только монтирование тестового `/tmp`; исходные отказы сохранены,
проверки продукта не ослаблялись. Файлы публичных APT-доказательств возвращены
владельцу рабочего каталога с правами 0600/0700.

Graphify обновлён и включает новую регрессию. Первая запись manifest не
удалась при лимите виртуальной памяти 1 ГиБ; повтор с ограничением потоков
и 2 ГиБ прошёл. Code Graph MCP не ответил за 300 секунд, CLI сообщил об
отсутствии индекса этого проекта; чужой граф не использовался.

Доказательства: `~/.local/state/hcp-evidence/dependency-update-20261116-7xrx0p44/`.
`receipt.json`, `regressions.log/json`, подписанные InRelease, keyring,
policy и симуляция сохранены отдельно от runtime.

## Границы первичного среза

Это локальное исправление сборки, **не обновление уязвимых библиотек**.
На момент первичного исправления полный новый образ, CI и установка ещё
не были выполнены; продолжение приведено ниже.
Рабочая панель остаётся на `ffd6881` / `00f0ad6c`, healthy, `/login` — 200;
настройки панели и Astra не менялись. Прежние 766 строк Trivy, включая
12 CRITICAL / 184 HIGH, не пересчитывались и не объявлены устранёнными.
