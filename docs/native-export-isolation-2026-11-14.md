# Изоляция HTML-экспорта OpenSCAP — 14 ноября 2026 года

HCP теперь передаёт пустые `--oval-template` и `--sce-template` при
`oscap xccdf generate report`. Это отключает автоматический поиск соседних
`*.result.xml`; вложенные результаты ARF продолжают использоваться. Команда
OVAL и скачивание исходных XML не меняются.

Причина проверена по подписанному исходному пакету OpenSCAP
`1.3.7+dfsg-1+deb12u1`: `utils/oscap-xccdf.c:902-934,1122-1138` проверяет
существование файла из `check-content-ref/@href` и включает шаблон
`%.result.xml`. XCCDF stylesheet затем вызывает `document()` для такого пути.
Фиксированного имени stylesheet недостаточно, чтобы исключить вторичные чтения.
