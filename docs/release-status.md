## Контракты и оригиналы

- Сохранённая OVAL-политика передаёт `evidenceProjection` исполнителю.
  По умолчанию bounded; detailed допустим явно. Компактная форма сохраняет
  каждый ID и точный результат.
- Новая `platformApplicability` — объект; старая строковая форма читается.
  Unknown/foreign, неполные, дублированные и неизвестные результаты не дают proof.
- Подтверждение устранения требует false исходного определения, той же базы,
  актива и поколения подключения. Смена базы не означает исправления CVE.
- HCP сохраняет оценённый source XML и ARF/OVAL results до очистки staging в
  `reports/.raw-evidence/<report-id>/`: каталоги 0700, файлы 0600. `rawEvidence`
  связывает пути, размеры и SHA с исходным JSON и его asset binding.
- Нет оригинала — новый отчёт partial; ссылка, неверный тип/размер или checksum
  останавливают публикацию. Копирование потоковое, оригиналы входят в backup.
  Проверка сохранения настоящим OpenSCAP на синтетическом source — отдельная
  фикстура, включая подставленную Astra identity.
- Origin учитывает forwarded authority/protocol только при явном доверии
  `HCP_TRUSTED_TLS_PROXY`. Учтена переписанная Next.js схема `nextUrl`.
  Production HTTP-регрессия воспроизводила прежний 400 и требует 403 до dispatch;
  положительный HTTPS Origin за доверенным прокси также проверен.

Исторические оригиналы и прежний ошибочный верхний OVAL-флаг не исправлялись
задним числом. Подлинность производителя и полнота CVE не выводятся из JSON.

## Эксплуатационные ограничения

- Фактический listener после обновления — `127.0.0.1:3000`, используется прежний
  host-network override. До переключения проверено 19 адресов управляющей

  проверка локального стенда; публичный HTTPS, rate limit и внешний peer review открыты.
- `main` защищена: PR, strict checks `web`, `ansible`, `container`, `lab` от
  GitHub Actions (app 15368), включая администратора; force push и удаление
  запрещены, обсуждения должны быть закрыты. Обязательных одобрений — 0;
  фактический peer review релиза остаётся отдельным условием.
- В RC общий `Required platform checks` всегда проверяет четыре результата;
  failed/cancelled/skipped/пустое значение дают отказ. Проверены 22 случая и
  mutation bypass. [Целевая политика общего gate](../.github/branch-protection-main.json)
  применяется после включения workflow в main, чтобы не заблокировать PR из
  прежней main без этого job. Текущая main исходников не изменялась.
