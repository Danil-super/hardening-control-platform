# Локальный комплект восстановления — 12 ноября 2026

По решению оператора подготовлена локальная копия. Внешний диск или сервер/NAS
не использовались. Независимое хранение backup и контрольных меток остаётся
открытым этапом.

Версия установленного приложения: `89b25ac5506985adde50db702988d108cd86dd45`.
Образ: `sha256:79cee278f3ac4c96c64e5782a053b8ade478c1d7f5686bcf88e1a53785559902`.
Программа не обновлялась. См. [очищенный протокол](evidence/local-recovery-package-2026-11-12.json).

## Что подготовлено

В закрытом каталоге вне Git находятся:

- `backup/`: согласованные runtime, настройки, сохранённый Docker-образ и
  `SHA256SUMS`. Полный набор — 1 563 915 547 байт, около 1,46 ГиБ.
- `controller.env`: фактическое окружение контейнера для точного восстановления.
- `tools/`: исходники версии приложения с утилитами проверки и инструкцией.
- `anchors/`: SHA-256 manifest, последняя метка HMAC и число событий,
  хеши окружения и архива исходников. Ключ HMAC в эту контрольную запись не входит.
- `README-TRANSFER.txt`: состав переносимого комплекта и порядок проверки.

Архивы и окружение содержат секреты. Они не добавлены в Git; каталоги имеют
права 0700, файлы комплекта — 0600. Отдельный локальный каталог anchors пока
не считается независимым хранилищем. SHA256SUMS сам по себе не защищает от
одновременной подмены архивов и контрольного списка.

## Фактические проверки

Перед копированием проверено отсутствие активных операций. Панель остановлена
для checkpoint SQLite и копирования runtime, затем запущена; пауза составила
78,417 секунды. Хеши 13 проверяемых таблиц и всех 119 файлов отчётов сохранились.
Образ сохранён по фактически установленному ID, commit.txt соответствует его
OCI revision, а не более новому локальному коммиту документации.

Архивы проверены штатным verifier, затем ещё раз утилитой, распакованной
только из подготовленного архива исходников. Состав TAR и полный manifest
прошли проверку. Комплект позволяет выполнять эту проверку без рабочей копии
репозитория и повторной установки пакетов из сети.

Сохранённый образ загружен из архива, данные восстановлены в новый каталог.
Копия запущена в отдельной внутренней Docker-сети, без опубликованных портов,
с лимитом 3 ГиБ без swap контейнера. Тестовые ВМ не запускались.
Проверены:

- полные байты критических файлов, целостность SQLite и 277 HMAC-событий
  с защитой содержимого и совпадением заранее снятой локальной контрольной метки;
- 34 активных и 41 архивный отчёт;
- PDF со всеми 4135 ID находок и SHA исходного JSON;
- исходный XML с SHA, совпадающим с manifest соответствующего отчёта;
- вход, 401 без сессии, 403 при чужом Origin и отклонение ранее действовавшей
  контролируемой cookie после отзыва сессии на остановленной копии.

Локальный прогон восстановления занял 346,079 секунды. Образ уже присутствовал
в Docker store; это измерение не является обещанием времени восстановления
на другой машине. Восстановленная копия остановлена. Основной сайт healthy,
его данные сохранены. Числа контроля памяти приведены в очищенном протоколе.
