# Краткая инструкция по работе с сайтом

1. Откройте сайт и убедитесь, что в левом меню указан демо-режим. В этом режиме платформа не меняет реальную операционную систему.
2. Перейдите в раздел `Профили` и выберите подходящий профиль аудита: базовое усиление Linux, безопасность SSH, усиление веб-сервера или усиление Docker-хоста.
3. Нажмите `Запустить аудит`. Сайт покажет этапы демо-проверки и перенаправит на страницу результатов.
4. На странице результатов изучите оценку защищенности, количество рисков и таблицу найденных проблем. Используйте фильтры по риску и категории.
5. Нажмите `Перейти к исправлениям`, чтобы открыть планировщик исправлений.
6. В планировщике выберите нужные действия. Для каждого действия показаны риск, затрагиваемые файлы, необходимость резервной копии, доступность отката и шаги выполнения.
7. Нажмите `Применить демо`. Сайт имитирует создание резервной копии, применение исправлений, проверку и повторный аудит.
8. Перейдите в раздел `Отчеты`, чтобы увидеть сравнение “до/после”, список исправленных и оставшихся проблем, ручные рекомендации и записи резервных копий.
9. При необходимости нажмите `Экспорт JSON` или `Экспорт HTML`, чтобы скачать отчет.
10. Раздел `Локальный Linux-агент` показывает, как веб-платформа взаимодействует с реальными audit-only проверками хоста.

## Импорт результата реального агента

1. Перейдите в папку `agent`.
2. Для разового запуска запустите локальный промежуточный сервер:

```bash
python3 server.py
```

3. Для установки как systemd-сервис сначала проверьте план:

```bash
./install.sh --dry-run
```

4. Затем при необходимости установите и запустите сервис:

```bash
sudo ./install.sh --enable --start
```

5. Проверьте агент:

```bash
./doctor.sh
curl http://127.0.0.1:8765/health
```

6. На сайте откройте `/agent/import`.
7. Выберите профиль и нажмите `Получить аудит от агента`. Для расширенной проверки включите переключатели `Включить расширенный аудит Lynis` и/или `Включить аудит OpenSCAP / SCAP Security Guide`.
8. Каждый успешный импорт сохраняется в истории браузера.
9. Чтобы сравнить два результата, выберите базовый и текущий отчет в блоке `Сравнение отчетов`.
10. Если автоматический запрос недоступен, выполните:

```bash
python3 agent.py audit --profile basic_linux --pretty > agent-report.json
```

11. Загрузите файл `agent-report.json` на странице `/agent/import`.
12. Для удаления сервиса используйте:

```bash
sudo ./uninstall.sh --dry-run
sudo ./uninstall.sh --remove-files
```

## Демо-хост / источник аудита

В MVP аудит выполняется на демонстрационном хосте `demo-ubuntu-24.04.local`. Источник данных — локальный демонстрационный движок.
Это значит, что сайт показывает реальный пользовательский сценарий платформы, но не выполняет системные команды и не меняет ОС.

Такой режим нужен для безопасной демонстрации на Vercel. Реальный аудит уже можно показать отдельно через локальный Python-агент и страницу `/agent/import`.
