# Локальная проверка подписи InRelease Debian

Этап задачи #12. Выполняется только для точного ID=debian штатным сборщиком инвентаря HCP. Не требуется ручных команд на хосте или доступа в интернет; Astra Linux и Ubuntu не наследуют доказательства Debian.

## Что проверяется

Сборщик ищет не более 12 локально сохранённых InRelease в /var/lib/apt/lists для точного Debian codename. Каждый файл и установленный /usr/share/keyrings/debian-archive-keyring.gpg читаются с ограничением 4 МиБ, проверкой типа файла, без символьных ссылок. gpgv (до 12 секунд на файл) проверяет PGP-подпись по локально установленному набору ключей. Проверяются подписанные Origin=Debian, точный Codename и наличие Date. Сохраняются SHA-256 файлов InRelease, SHA-256 локального keyring, отпечатки подписантов, выпуски и агрегированные результаты. Репозиторные URL, имена файлов и содержимое InRelease не публикуются.

Состояние verified_with_local_keyring означает, что все выбранные InRelease проверены локальным gpgv; при ошибках или недоступности возвращается partial/unavailable. Прежние наблюдения apt-cache policy остаются отдельными.

## Границы доверия

Подлинность самого набора ключей Debian не установлена независимо: он взят с оцениваемого хоста. SHA-256 этого keyring не является независимым операторским PIN. Проверка не охватывает хеши Packages против подписанного Release, связи Packages с архивом .deb или фактическими установленными файлами, а также актуальности данных издателя. Поля publisherAuthenticated, publisherFreshnessVerified, packageIndexHashesVerified, installedPackageOriginVerified, remediationAuthorized всегда false. Только localSignatureVerified может быть true при успешном gpgv.

Исходный Trivy, предварительный Debian Security Tracker и решение о remediation не переписываются. Отсутствие уязвимостей не превращается в доказательство защищённости хоста.

## Приёмочные испытания

Python unit tests проверяют bounded/no-follow чтение, неправильную подпись, spoofed OS, Python 3.5. Node-тесты проверяют структурное сохранение и запрет эскалации доверия, итоговый JSON и действительный PDF. Нативная Debian 12 VM после apt update проверяет подписи реальным gpgv, не утверждая аутентификацию издателя или происхождение пакетов.

Дальнейшая задача: независимо закреплённый trust anchor и проверка цепочки подписанный Release → хеш Packages → точный бинарный пакет/версия → установленный артефакт. Одна локальная подпись не удостоверяет всю цепочку.
