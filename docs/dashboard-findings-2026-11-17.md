# Обзор: ограничения проверок и критичность OVAL

На сохранённой учебной Astra воспроизведено: 7 свежих проверок, 2 неполных,
1 исторический отчёт вне текущей привязки. Это разные причины, а не ошибка
подключения хоста:

- Локальные правила: `nftables` возвращает часть условий как `xt:null`.
  Автоматическая оценка INPUT ограничена; повтор с тем же форматом не исправит её.
- Trivy: не оценены системные пакеты Astra. Отдельный успешный OVAL-аудит уже
  есть, но он не превращает собственный результат Trivy в полный.
- Старый Greenbone: идентичность актива не сохранена, поэтому отчёт исключён.
  Присоединять его к текущему активу автоматически нельзя.

Баннер «Уточните неполные результаты» дублировал статус без конкретного действия.
Для свежих известных результатов он убран; у хоста показаны причины и ссылки
на отчёты. Ограничения продолжают учитываться, статус не переводится в зелёный.

Из 1909 находок без оценки 1856 относились к OVAL, 53 — к Lynis. В исходном
XML OVAL обнаружена потеря данных адаптером: он читал `severity`, но пропускал
числовой CVSS 3.x в поле БДУ. На тех же определениях восстановлены 1748 оценок:
234 критические, 702 высокие, 713 средние, 99 низкие. Используется опубликованный
числовой балл и [шкала FIRST](https://www.first.org/cvss/v3.1/specification-document#Qualitative-Severity-Rating-Scale),
а не предположение по описанию. Явные прежние оценки производителя/Chromium
сохраняют приоритет.

108 OVAL-записей остаются без оценки: у 66 есть только вектор без числового
балла, у 32 значение CVSS 3.x — `None`, у 10 поля нет. Вычисление балла по
вектору не добавлено. После установки вместе с 53 рекомендациями Lynis получена 161 находка
без оценки. Lynis в этом отчёте передал советы/предупреждения без уровней CVSS;
это не является ошибкой выполнения проверки.

Старые JSON/XML и созданные PDF не переписываются. При чтении старого отчёта
CVSS восстанавливается из оригинала с проверкой SHA-256, пути, типа файла и
изменения содержимого. XML разбирается отдельным процессом с пределами памяти,
времени и размера. Новые запуски сохраняют CVSS сразу в структурированных
метаданных. Оценка CVSS также включается в новые PDF HCP.

Число находок не уменьшается: меняется только их классификация. CVSS описывает
серьёзность; применимость к роли хоста и решение об исправлении требуют разбора.
