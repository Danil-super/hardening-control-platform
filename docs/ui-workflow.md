# Рабочие страницы HCP

Изменения интерфейса от 10 ноября 2026 года. Цель — оставить на первом плане
выбор, параметры, действие и результат. Повторяющиеся объяснения удалены;
инструкции, YAML, файлы, контрольные суммы и доказательства раскрываются отдельно.
Ошибки, неполнота проверки и подтверждения изменения настроек остаются видимыми.

## Порядок действий

| Страница | Последовательность |
| --- | --- |
| Обзор | Состояние → следующее действие → сводка находок |
| Хосты | Выбор/подключение → инструмент и параметры → подготовка/пароль → запуск → результат → firewall → восстановление |
| Сценарии | Выбор → цель и параметры → YAML при необходимости → сохранение/проверка → запуск → результат |
| План работ | Хост → находки → решения → повторная проверка |
| Итоговые PDF | Хост и реквизиты → формирование → сохранённые PDF |
| Источники | База Trivy → актуальность → источник OVAL → назначения → справочные материалы |
| Политики | Профиль группы → исключения с причиной и сроком |
| Отчёты | Выбор отчёта → состояние/сводка → оригиналы → находки; технические параметры отдельно |
| Инструкция | Выбор темы → подробные шаги; ссылки с `#темой` раскрывают нужный раздел |

Выбор «Проверки» у подключённого хоста отделён от «Настроить». Сворачивание
не размонтирует формы и не сбрасывает поля. Запуск остаётся на существующих
API, с прежними проверками параметров, прав, подтверждений и одноразовых паролей.
Никакое раскрытие секции не запускает аудит или изменение firewall.

## Проверка

- 612 web-тестов, 119 HTTP-проверок, TypeScript и production-сборка.
- Chromium: основные страницы при 320, 768, 1024 и 1440 px; без переполнения
  страницы и ошибок JavaScript. Широкие таблицы прокручиваются внутри своих блоков.
- Выбор хоста без открытия SSH-формы; открытие настройки и сохранение поля
  после сворачивания; выбор Lynis и формирование запроса для нужного хоста.
- Параметры сценария расположены перед кнопками; YAML раскрывается отдельно.
- Раскрытие находки с клавиатуры сохраняет описание, рекомендацию и доказательства.
- Прямые ссылки на firewall и Greenbone открывают соответствующие темы.

Браузерный запуск задания моделировался в изолированной установке; сканеры
и изменения ВМ в этой проверке не выполнялись. Данные хостов и плана для UI
взяты из сохранённого снимка; это не новая операторская приёмка аудита.
Изменения локальные, отдельный GitHub CI нового SHA не запускался.

## Отчёты отдельных запусков

«Отчёт HCP» содержит отдельный PDF запуска и нормализованный JSON. «Отчёт инструмента»
содержит просмотр и скачивание сохранённых оригиналов. Недоступность оригинала
показана явно. Сравнение с прошлыми областями проверки свёрнуто отдельно от статуса
сканера; ссылки ведут к старому и новому запуску. После основной кнопки запуска
до сетевой панели — 20 px, внутри сетевых действий используются отдельные отступы.

Проверены фактические скачивания PDF и неизменённого ARF, ошибка PDF с повторным
включением кнопки, 320/390/1440 px. PDF с 4000 находками не обрезает описания.
Подробности и пределы экспорта: [интеграции](audit-integrations.md).

На рабочей установке повторно скачаны PDF сохранённых OpenSCAP (18) и OVAL
(4135 записей); проверены все ID и SHA-256 сохранённого JSON. Фикстура с неизвестной
прежней областью подтверждает отдельный свёрнутый блок сравнения и обе ссылки.

JSON HCP теперь скрыт внутри «Технические данные». Реальный проход сценария,
плана и архивов на отдельной SSH-цели: [протокол](offline-acceptance-2026-11-10.md).
