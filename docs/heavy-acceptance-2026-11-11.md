«Хосты» → reload. На сервере сохранился тот же активный job ID; оба снимка
состояния после переходов/reload — running. Проверены 1280×800, 1440×1000,
1920×1080; нет JS-ошибок и переполнения страницы.

У прежнего большого OVAL-отчёта последовательно скачаны три PDF, затем XML
и HTML OpenSCAP. В отдельном одновременном запросе трёх PDF сработал предел
двух рендеров: один ответ 429, затем его повтор успешно скачан. Потери исходных
данных или подмены файла JSON вместо PDF нет. У свежих отчётов скачаны PDF
HCP и XML/source XML/DAT инструментов; все длины и SHA оригиналов совпали
с rawEvidence. Для сгенерированного HTML сверена ссылка на SHA исходного XML.

Проверено 15 успешных API-скачиваний, из них 9 PDF. Дополнительно после
завершения аудитов кнопка сайта скачала свежий OVAL PDF, открыт native HTML
с заголовком OVAL Results и CVE выбранного результата. Это отдельная проверка
интерфейса, а не утверждение о нажатии кнопки в ходе активного сканирования.

Всего проверены 10 PDF. В каждом присутствуют все ID соответствующих находок,
а во всех OVAL PDF — все 4068 CVE. SHA исходного JSON в PDF-выгрузках совпадает
