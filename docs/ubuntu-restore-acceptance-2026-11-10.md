# Восстановление текущего HCP на отдельной Ubuntu — 10 ноября 2026

Текущий образ HCP перенесён в новую Ubuntu KVM-ВМ без пересборки. Из неё
выполнены новое закреплённое SSH-подключение к рабочей Astra SE 1.7.6.15
и настоящий OpenSCAP. Это подтверждает перенос контроллера и новый аудит;
полная эксплуатационная приёмка #43 остаётся открытой.

Код: `4bcb500e6b287f72d64ae91bb4d95ee2862b1252`.
Образ: `sha256:84828d4e8ac95b42abe69343153ab7aa042135959a42fe59a9f2d2bee72a329d`.
Численные результаты и SHA: [очищенный протокол](evidence/ubuntu-restore-2026-11-10.json).

## Среда и изоляция

Отдельная Ubuntu 24.04, kernel 6.8.0-147-generic, Docker 29.1.3;
2 vCPU / 4 ГиБ RAM. Официальный cloud image проверен по закреплённому
SHA-256 и подписи SHA256SUMS через установленный Ubuntu Cloud keyring.
SSH host key новой Ubuntu задан заранее и сверен с консолью.

До переноса секретов QEMU запрещал исходящую сеть; запрет проверен настоящими
соединениями. Во время живого этапа исходная панель остановлена, а гостю
разрешён только нужный SSH к Astra, loopback, DHCP и ответный трафик.
Публичное исходящее соединение отклонено. Файлы и правила основной Ubuntu
и Astra для настройки этой изоляции не менялись.

Обе Ubuntu находятся на одном физическом компьютере. Pins манифеста и
конца журнала сохранены отдельно от backup, но на исходном компьютере.
Это не внешнее резервное хранилище и не независимая подпись ответственного.

## Промежуточные отказы и границы

Проверки завершены после исправления испытательных скриптов: обязательный
выходной файл отзыва сессий, синтаксис гостевой nft-политики, перенос Compose
healthcheck и ожидание штатного HTTP 202 при создании задания. Защитные
проверки продукта не отключались, его код в этом этапе не менялся.
Неуспешные протоколы и резервные копии сохранены отдельно.

В одном промежуточном запуске identity API вернул 409. Тело ответа тогда
не сохранялось; причина не подтверждена. Новый SSH основной панели и повтор
из той же восстановленной копии прошли. Это не доказательство устранения
всех возможных сетевых отказов. Следующие неожиданные ответы сохраняются
испытательным скриптом приватно, без паролей и cookie.

Из этой Ubuntu не выполнялось новое изменение/восстановление firewall;
ранее принятый UFW-цикл описан в [живом протоколе](live-acceptance-2026-11-10.md).
HTTPS, внешнее хранение anchors, нагрузка 1/3/5 хостов, новый GitHub CI
и подпись оператора остаются открытыми. Trivy/Astra unsupported и manual
для legacy packet filtering сохраняются.

Приватный комплект: `~/.local/state/hcp-evidence/ubuntu-dr-20261110-jbhsr0sm/`.
Архивы, SQLite, ключи, env и cookie в Git не добавлялись. Гостевая Ubuntu
выключена, основная панель доступна на `http://127.0.0.1:3000`.
