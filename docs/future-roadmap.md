# Roadmap

## Реализовано

- Безагентное подключение к Linux-хостам по SSH через Ansible.
- Отдельные версионированные профили: Linux, SSH, web-сервер и Docker-host.
- Инвентаризация пакетов, CycloneDX SBOM и CVE-проверка через Trivy с vendor-aware статусами.
- Отчеты аудита в JSON с доказательствами и историей по хосту.
- Транзакционные обратимые firewall-изменения: dry-run, подтверждение alias, backup, повторный аудит и rollback.
- SQLite-хранилище транзакций и hash-chain журнал операций.
- Устойчивый системный запуск периодического аудита через systemd timer и `flock`.
- Лабораторный Docker-стенд с намеренно небезопасной SSH-конфигурацией и открытым Telnet-портом.
- GitHub Actions для typecheck, тестов, сборки, Ansible syntax-check и Docker build.

## Следующие этапы

1. Многопользовательская аутентификация, роли (аудитор/оператор/администратор), сессии с отзывом и MFA.
2. Внешний TLS reverse proxy, VPN-доступ к панели и централизованная политика доступа.
3. Поддержка RHEL, AlmaLinux и Rocky Linux с отдельными профилями и vendor security tracker.
4. Более точный CVE-адаптер для дистрибутивных пакетов с учетом epoch и backport-исправлений.
5. Approval workflow с окном обслуживания для необратимых операций: обновление пакетов, перезапуск/остановка сервисов.
6. Выделенный worker и очередь для долгих проверок с индикатором прогресса и повторными попытками.
7. Интеграция с IDS/SIEM как источником инцидентов, а не замена этих систем.
