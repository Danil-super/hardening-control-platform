# Roadmap

## Уже реализовано

- Веб-платформа на Next.js с русскоязычным интерфейсом.
- Четыре профиля аудита: базовый Linux, SSH, веб-сервер и Docker-хост.
- Демонстрационный аудит, результаты проверок, план исправлений, имитация резервных копий и отчет “до/после”.
- Экспорт JSON и HTML для отчетов.
- Локальный Ansible-контур для главного сервера.
- Автообнаружение SSH-доступных хостов в приватной локальной подсети.
- Таблица управляемых хостов из `ansible/inventory.ini`.
- Безагентный сбор фактов и безагентный audit-only отчет.
- Response-playbook для закрытия распространенных опасных портов через активный `ufw`/`firewalld`.

## Следующие этапы

1. Расширить безагентные Ansible-проверки до полного покрытия всех демонстрационных профилей.
2. Добавить подключаемые YAML-правила для agentless-проверок.
3. Подключить источники событий для обнаружения атак: логи firewall/роутера, Suricata или другой IDS на шлюзе.
4. Добавить журнал инцидентов и статусы реагирования.
5. Реализовать реальные резервные копии, исправления и откат для response-playbook'ов.
6. Добавить контейнеризированную локальную среду для разработки и показа.
7. Добавить адаптеры RHEL, AlmaLinux и Rocky Linux.
8. Добавить авторизацию и роли операторов.
9. Настроить стабильный release workflow для GitHub и локального развертывания.
