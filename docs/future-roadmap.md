# Roadmap

## Уже реализовано

- Веб-платформа на Next.js с русскоязычным интерфейсом.
- Четыре профиля аудита: базовый Linux, SSH, веб-сервер и Docker-хост.
- Демонстрационный аудит, результаты проверок, план исправлений, имитация резервных копий и отчет “до/после”.
- Экспорт JSON и HTML для отчетов.
- Локальный Python-агент для Ubuntu/Debian в безопасном режиме “только аудит”.
- Опциональная интеграция Lynis с нормализацией WARNING/SUGGESTION в `Finding`.
- Bridge-сервер для автоматического импорта отчета агента в сайт.
- История импортов и сравнение двух агентских отчетов.
- План исправлений по реальному отчету агента без применения изменений.

## Следующие этапы

1. Расширить проверки агента до полного покрытия всех демонстрационных профилей.
2. Добавить подключаемые YAML-правила для Linux-проверок.
3. Улучшить интеграцию Lynis:
   - сохранять сырой вывод и exit-код;
   - добавить чтение `/var/log/lynis-report.dat`, если он доступен;
   - расширить маппинг test-id в категории и remediation-план.
4. Подключить OpenSCAP/SCAP Security Guide после стабилизации Lynis:
   - выбор профиля SCAP под ОС;
   - запуск `oscap xccdf eval` в audit-only режиме;
   - импорт ARF/XML-результатов;
   - нормализация rule result в `Finding`;
   - отдельный отчет compliance по выбранному профилю.
5. Реализовать реальные резервные копии, исправления и откат.
6. Добавить контейнеризированную локальную среду для разработки и показа.
7. Добавить адаптеры RHEL, AlmaLinux и Rocky Linux.
8. Добавить авторизацию и инвентаризацию нескольких серверов.
9. Настроить стабильный release workflow для GitHub и Vercel.
