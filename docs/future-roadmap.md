# Roadmap

## Уже реализовано

- Веб-платформа на Next.js с русскоязычным интерфейсом.
- Четыре профиля аудита: базовый Linux, SSH, веб-сервер и Docker-хост.
- Демонстрационный аудит, результаты проверок, план исправлений, имитация резервных копий и отчет “до/после”.
- Экспорт JSON и HTML для отчетов.
- Локальный Ansible-контур для главного сервера.
- Автообнаружение SSH-доступных хостов в приватной локальной подсети.
- Таблица управляемых хостов из `ansible/inventory.ini`.
- Безагентный сбор фактов и безагентный audit-only отчет.
- Response-playbook для закрытия распространенных опасных портов через активный `ufw`/`firewalld`.
- Планировщик периодических audit-проверок.
- Журнал инцидентов и статусы реагирования.
- Расширенный безагентный аудит SSH, sudo, логов входа, сервисов и прав директорий.
- Response-playbook'и для закрытия конкретного порта, блокировки IP и остановки systemd-сервиса.
- Сбор событий из auth/syslog/UFW/Suricata-логов через Ansible.

## Следующие этапы

1. Довести безагентные Ansible-проверки до полного покрытия всех демонстрационных профилей.
2. Добавить подключаемые YAML-правила для agentless-проверок.
3. Подключить внешний IDS/шлюз как основной источник атак, например Suricata на отдельном сетевом узле.
4. Реализовать реальные резервные копии, исправления и откат для response-playbook'ов.
5. Добавить контейнеризированную локальную среду для разработки и показа.
6. Добавить адаптеры RHEL, AlmaLinux и Rocky Linux.
7. Настроить стабильный release workflow для GitHub и локального развертывания.
