# Описание дипломного проекта

**Тема:** разработка веб-платформы для безагентного аудита и контролируемого харденинга Linux-серверов.

Hardening Control Platform разворачивается на выделенном Linux control node в приватной сети. Она подключается к управляемым хостам по SSH через Ansible, не устанавливает на них постоянные агенты и хранит результаты в локальном контуре.

## Реализованный сценарий

1. Администратор добавляет хост в Ansible inventory и выполняет SSH preflight.
2. Выбирает один из реальных профилей: базовый Linux, SSH, web-сервер или Docker-host.
3. Платформа запускает соответствующий набор проверок на хосте и сохраняет JSON-отчет с доказательствами.
4. Для пакетов формируется отдельная CVE-проверка через OSV.dev; результат обозначается как предварительный и требует учета backport-исправлений дистрибутива.
5. Обратимое изменение firewall проходит через dry-run, ввод alias целевого хоста, резервную копию конфигурации, применение и повторный аудит.
6. Администратор может выполнить откат из сохраненного архива firewall-конфигурации.
7. Каждое выполнение и изменение заносится в локальную SQLite-базу с hash-chain журналом, защищающим историю от незаметного изменения.
8. Регулярный аудит выполняется внешним systemd timer, поэтому не зависит от жизненного цикла Next.js-процесса.

## Границы системы

Платформа не является SIEM, IDS или сервисом публичного сканирования. Она предназначена только для активов, на аудит и изменение которых у администратора есть разрешение. Для текущей версии поддерживаются обратимые firewall-действия: закрытие конкретного порта и блокировка IPv4-адреса. Обновление пакетов и управление сервисами оставлены ручными процедурами, так как общий безопасный автоматический rollback для них не гарантируется.
