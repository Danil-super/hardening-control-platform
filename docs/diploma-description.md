# Описание дипломного проекта

Тема: разработка расширяемой веб-платформы для аудита и безопасного харденинга Linux-серверов с поддержкой планирования исправлений, резервных копий, отката и отчетности “до/после”.

Проект показывает полный сценарий управления безопасностью:

1. Выбор профиля аудита.
2. Запуск демонстрационного аудита.
3. Просмотр найденных проблем и уровней риска.
4. Выбор действий по исправлению.
5. Имитация резервной копии и применения исправлений.
6. Повторный аудит.
7. Экспорт отчета “до/после” в JSON или HTML.

Дополнительно реализован локальный контур главного сервера: Ansible inventory, автообнаружение SSH-доступных хостов, безагентный сбор фактов, безагентный аудит и response-playbook'и для реагирования после подтверждения администратора.

MVP безопасен для публикации на GitHub и Vercel: веб-сайт не требует root-доступа и не выполняет системные команды на сервере деплоя. Реальный Ansible-контур работает только при локальном запуске на главном сервере внутри сети. Платформа не заменяет IDS или SIEM; она является управляющим слоем для аудита, инвентаризации и запуска заранее разрешенных действий реагирования.
