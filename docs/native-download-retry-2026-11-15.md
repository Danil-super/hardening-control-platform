# Повтор загрузки источников в native CI

Прогон Astra 1.8.1 кода `97b4bef` завершился до аудита из-за
`TimeoutError` при чтении официального OVAL. Повтор только этого job прошёл.
Загрузчик тестового стенда `deployment/tests/verify_astra_vm.py` прежде
прерывал весь эксперимент после первого такого отказа. В отличие от него,
рабочий `hcp-oval-audit.py` уже имел три попытки; он этим изменением не затронут.

Общий CI-клиент теперь делает не более трёх попыток при timeout/reset
соединения, включая `URLError` с такой причиной. Каждая начинает с нуля:
частичный файл удаляется, счётчик размера и SHA-256 создаются заново.
Общее значение `max_seconds` не сбрасывается; следующему соединению передаётся
не более оставшегося времени. Время проверяется также после EOF, прежде чем
принимать файл. Ошибка сертификата, HTTP-ошибка, неправильный размер или hash
завершают проверку без повторов. Кэш по-прежнему проверяется по точным байтам.

Сигнатура сохранена. Проверены все вызывающие: Astra 1.8, native QEMU 1.7
и полный vendor OVAL 1.7. Изменены только CI helper и его регрессии;
состав/код установленного образа `97b4bef` / `3a6d15a4` не меняются.

## Проверка

- RED воспроизвёл отсутствие повтора и потерю проверки после EOF.
- Все 18 точечных и 246 deployment-тестов прошли. Полный набор выполнялся
  в отдельном контейнере 512 МиБ без сети и без runtime/секретов панели.
  Минимум MemAvailable — 8 786 599 936 байт, OOM/guard не сработали.
- На настоящем собственном HTTPS-сервере первый ответ обрывается тайм-аутом
  после первого МиБ. Прежняя версия делает один запрос и не публикует файл;
  новая делает два и сохраняет все 1 048 616 байт с правильным SHA-256.
  Проверка сертификата и имени включена; временный ключ удалён.
- Отрицательный контроль инвертировал классификацию ошибки только в частной
  копии исходников. Регрессии обнаружили изменение; рабочий код не подменялся.

Материалы: `~/.local/state/hcp-evidence/ci-download-20261115-51apdnwe/`.
Официальная документация через Context7:
[urlopen](https://docs.python.org/3/library/urllib.request.html#urllib.request.urlopen),
[URLError.reason](https://docs.python.org/3/library/urllib.error.html#urllib.error.URLError),
[SSLContext](https://docs.python.org/3/library/ssl.html#ssl.create_default_context).

Это восстановление после конкретного временного отказа, не гарантия
доступности сервера производителя. Socket timeout ограничивает блокирующую
операцию, а не DNS/весь поток; существующий внешний deadline CI сохраняется.
Поздние байты не принимаются, но жёсткое прерывание любого системного вызова
ровно в `max_seconds` не заявляется. Свежая проверка GitHub нового SHA
фиксируется отдельно после публикации.
