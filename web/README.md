# Веб-приложение Hardening Control Platform

Демо-веб-приложение для аудита Linux, планирования исправлений, имитации резервных копий, централизованного Ansible-управления и отчетности “до/после”.

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить сервер разработки:

```bash
npm run dev
```

Собрать проект:

```bash
npm run build
```

Основные маршруты:

- `/` панель проекта
- `/profiles` профили аудита
- `/audit/[profileId]` запуск демо-аудита
- `/audit/[profileId]/results` таблица найденных проблем
- `/remediation` планировщик исправлений
- `/reports` отчет “до/после” с экспортом JSON и HTML
- `/guide` инструкция по работе
- `/hosts` локальный центр Ansible: inventory, автообнаружение, безагентный аудит и response-playbook'и

Демо-режим не выполняет системные команды и не изменяет ОС хоста. Реальное управление доступно только при локальном запуске сайта на главном сервере в сети.
