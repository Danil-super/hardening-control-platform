# Веб-приложение Hardening Control Platform

Демо-веб-приложение для аудита Linux, планирования исправлений, имитации резервных копий и отчетов “до/после”.

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить сервер разработки:

```bash
npm run dev
```

Собрать проект:

```bash
npm run build
```

Основные маршруты:

- `/` панель проекта
- `/profiles` профили аудита
- `/audit/[profileId]` запуск демо-аудита
- `/audit/[profileId]/results` таблица найденных проблем
- `/remediation` планировщик исправлений
- `/reports` отчет “до/после”
- `/agent` контракт будущего Linux Agent

Демо-режим не выполняет системные команды и не изменяет ОС хоста.

## Vercel

Используйте стандартный preset Next.js. Если деплой выполняется из корня репозитория, укажите `web` как корневую директорию проекта.
